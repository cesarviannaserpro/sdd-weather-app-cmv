# Especificações (`specs/`)

Esta pasta guarda os artefatos de **especificação** produzidos no fluxo
Spec-Driven Development.

Você vai criar aqui, ao longo do treinamento:

- `discovery.md` — análise dos requisitos de negócio (Module 01)
- `personas.md` — hipóteses de usuários para orientar histórias e critérios de aceite
- `risks.md` — riscos técnicos e de produto identificados no discovery
- `weather-app-spec.md` — especificação completa do produto (Module 02)

> Não comece pelo código. Comece pela spec.
